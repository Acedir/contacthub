# 使用手册

## 安装与启动

```bash
pnpm install
pnpm dev
```

浏览器打开 `http://localhost:5173`。生产预览：

```bash
pnpm build
pnpm preview
```

## 首页

- 顶部搜索框支持姓名、公司、职位、生日、备注、标签、电话、邮箱、地址和社交账号。
- `Ctrl + K`（macOS 为 `⌘ + K`）聚焦搜索。
- 点击联系人卡片打开详情；`Enter` / `Space` 也可打开。
- 卡片右上角星标用于收藏；再次点击取消。

## 新建 / 编辑联系人

1. 点击右上角「新建联系人」。
2. 填写姓名（必填）、公司、职位、生日。
3. 在「联系方式」中按需添加：
   - 电话：手机、工作、家庭等；
   - 邮箱：个人、工作等；
   - 地址：家庭、公司等；
   - 社交：微信、微博、LinkedIn 等。
4. 标签用中英文逗号或分号分隔。
5. 打开「收藏这位联系人」可加入收藏。
6. 保存后自动写入浏览器 localStorage。

## 导入 Excel

1. 点击侧栏 / 顶栏「从 Excel 导入」。
2. 首次使用建议先「下载导入模板」。
3. 每个联系人一行；每一类联系方式按“标签列 + 值列”成对填写。
4. 上传后先预览：
   - 可导入联系人数量；
   - 缺少姓名被跳过的行数；
   - 提示信息。
5. 选择导入方式：
   - **智能合并**：按姓名匹配，补充新联系方式、标签、备注；
   - **全部追加**：全部作为新联系人。
6. 点击「导入 N 位联系人」。

支持的简单表头示例：

| 姓名 | 电话 | 邮箱 | 地址 | 收藏 | 标签 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 张三 | 13800000000 | zhang@example.com | 上海市…… | 是 | 朋友；客户 | 示例 |

## 导出 Excel

点击侧栏 / 顶栏 / 移动端底部的「导出」，浏览器会下载：

```text
拾光通讯录_YYYY-MM-DD.xlsx
```

每位联系人一行；基础信息各占一列；电话、邮箱、地址、社交按最大条数动态扩展。文件含「导入说明」Sheet，可直接重新导入。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl / ⌘ + K` | 聚焦搜索 |
| `Esc` | 关闭弹窗 / 详情抽屉 |
| `Enter` / `Space` | 打开聚焦的联系人卡片 |

## 数据与隐私

- 所有数据只存在于当前浏览器的 `localStorage`。
- 不上传服务器，不需要登录。
- 清理浏览器数据会删除联系人；请定期导出 Excel 备份。
- 重置示例数据：

```js
localStorage.removeItem('contacthub.contacts.v1')
location.reload()
```

## 常见问题

**为什么导入后多了/少了联系人？**  
导入预览会显示“可导入”和“跳过”的数量。缺少姓名的行会跳过；无联系方式但有姓名的行仍会导入。

**为什么同一个人的电话没有重复？**  
系统按“类型 + 规范化值”去重，电话号码会忽略空格、连字符和括号。

**为什么刷新后数据还在？**  
数据保存在浏览器 localStorage；换浏览器或设备需要重新导入 Excel。

**支持 `.xls` 吗？**  
不支持，请在 Excel 中另存为 `.xlsx`。
